
This repo contains a series of demos, games, game engines and tools (stripts)
for CircuitPython (https://circuitpython.org/) devices.

In Chapter 6 I want to develop an game engine (with example game) that
uses the best elements and features of the existing examples here.

at the same time, I also want to pursue these goals:
- make the code more idiomatic Python
- bring the code up to the latest CircuitPython (core and library) versions
- generalize for a range of CrcuitPython devices (with prerequiste hardware like screens and buttons).
