# Kenney — Roguelike/RPG pack (1,700+ tiles)

Pulled for bead `cd-e17.13`. See `Chapter_7/doc/REFERENCES.md` → *Extended
survey* (#4). Value for Ch7: environment tiles + **UI panels/buttons/sliders**
(feeds the HUD-heavy layout work in `cd-oht`). No creature or item sprites.

- **Source:** <https://opengameart.org/content/roguelikerpg-pack-1700-tiles>
  · also at <https://kenney.nl/assets/roguelike-rpg-pack>
- **Artist:** Kenney Vleugels (<https://kenney.nl>), 16×16 conversion by
  Lynn Evers (@EversLynn)
- **License:** **CC0** — personal + commercial use, credit appreciated but not
  mandatory. Full text in `License.txt`.

## What's here

- `Spritesheet/roguelikeSheet_transparent.png` — the packed sheet.
  **16×16 tiles with a 1px margin between them** (see `Spritesheet/spritesheetInfo.txt`).
- `Spritesheet/roguelikeSheet_magenta.png` — same, magenta key instead of alpha.
- `Map/*.tmx` — Tiled sample maps.
- `Preview.png`, `Sample1.png`, `Sample2.png` — overview images.

Perspective: top-down overworld. Floors, walls, roofs, flora, doors, windows,
furniture, mining props, flags/banners, and UI widgets.
