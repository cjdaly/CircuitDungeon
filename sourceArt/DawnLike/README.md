## What's here

`Characters/` (400+ creature sprites, 2-frame animation, paired `*0`/`*1`
frames), `Items/` (800+ item icons), `Objects/` (walls, floors — 48 sets —
doors, furniture, traps, effects, stairs incl. alternate up/down),
`GUI/` (menu frames + two monospaced TTF fonts), `Examples/` (Tiled `.tmx`
maps + preview GIFs), `Commissions/` (player-class sprites as PNG).

Perspective: top-down orthogonal with chunky "isometric-style" wall blocks —
the closest match in the survey to `Chapter_7/doc/ART.md` §1. Native 16x16.

Aseprite source files (`*.ase`) were dropped on import; PNG exports remain.
