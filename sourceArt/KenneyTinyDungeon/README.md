# Kenney — Tiny Dungeon (1.0)

Pulled for bead `cd-e17.13`. See `Chapter_7/doc/REFERENCES.md` → *Extended
survey* (#5). Clean, minimal CC0 all-rounder — the safety net if a Ch7 sheet
needs a placeholder or a silhouette check.

- **Source:** <https://kenney.nl/assets/tiny-dungeon>
- **Artist:** Kenney (<https://kenney.nl>), 2022-07-05
- **License:** **CC0** — personal, educational, and commercial use; credit
  appreciated, not mandatory. Full text in `License.txt`.

## What's here

- `Tilemap/tilemap.png` — sheet, **16×16 tiles, 1px spacing** (12×11 grid,
  132 tiles; see `Tilesheet.txt`).
- `Tilemap/tilemap_packed.png` — same sheet, no spacing.
- `Tiles/tile_0000.png` … — every tile as an individual file.
- `Tiled/` — Tiled `.tsx` + sample `.tmx`.
- `Preview.png`, `Sample.png` — overview images.

Perspective: top-down. Dungeon/sewer tiles, characters, monsters, items.
