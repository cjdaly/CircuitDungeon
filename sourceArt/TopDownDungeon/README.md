## What's here

- `tileset.png` — 304×208, the tilesheet. 16×16 tiles, "look best upscaled 2×".
  Zelda-like top-down (the author notes known perspective inconsistencies).
  Walls with wall-tops, floors, doors, stairs, chests, barrels, boxes, decor.
- `mockup.png` — the author's example room built from the sheet.

OGA served this as `sheet_16.png` / `sheet_17.png` (byte-identical); kept one,
renamed to `tileset.png`.
