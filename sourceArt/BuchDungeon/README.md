## What's here

- `tileset.png` — 368×384. Orthographic top-down. 16×16 tiles (can be
  subdivided into 8×8). Walls, floors, wooden doors, **stairs**, water +
  waterfall, boxes, chests, and basic unanimated mage / knight / dwarf sprites.
- `preview.png` — example scene.

Caveat (from OGA comments): tiles carry offset/margin spacing rather than
sitting on a tight grid — expect to re-pack before use.

OGA served this as `dungeon_tiles_0.png` / `dungeon_tiles_2.png`
(byte-identical); kept one, renamed to `tileset.png`.
