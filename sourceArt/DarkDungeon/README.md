# 16x16 Dark Dungeon Tileset (Zoltan Kosina)

Pulled for bead `cd-e17.13`. See `Chapter_7/doc/REFERENCES.md` → *Extended
survey* (#7). Small set — useful mainly for its **trap** and **fountain**
tiles. Built on the same 0x72 base as `../DungeonTilesetII/`, so it's
palette-compatible with that reference.

- **Source:** <https://kosinaz.itch.io/16x16-dark-dungeon-tileset>
- **Artist:** Zoltan Kosina, based on **0x72**'s *16x16 DungeonTileset II*
- **License:** **CC0** (Creative Commons Zero v1.0 Universal).

Per the itch page:

> Same as 0x72: You can use this tileset for whatever you like (CC-0). Credit
> is not necessary … you can still credit 0x72 and me if you feel like it.

## What's here

- `DarkDungeon.png` — 144×256, RGBA. 16×16 tiles, top-down. A darker/older
  floor, centred walls, 4 trap variants (above / below / front / side),
  8 fountains.
